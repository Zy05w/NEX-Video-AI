# 01 · 产品需求说明

> 版本：v1.0（2026-11-21）· 状态：已确认

## 1. 项目概述

NEX 视频增强是一款运行于 Windows 11 的本地桌面软件：用户导入视频后，通过 AI 模型进行**画质超分**（提升分辨率与清晰度）与**补帧**（提升帧率、画面更流畅），导出处理后的新视频（保留原音频）。定位与 SVFI、Topaz Video AI 同类，面向最终消费者**商业销售**。

## 2. 用户画像

- 主要用户：视频爱好者 / 内容创作者，不懂编程，需要"打开 → 导入 → 选参数 → 开始 → 导出"的傻瓜式流程。
- 硬件环境：Windows 11 + NVIDIA RTX 30/40/50 系显卡（支持 Vulkan，NVIDIA 驱动自带，无需额外安装运行库）。
- 用户电脑不需要安装 Python、CUDA 或任何开发环境。

## 3. 功能清单（v1）

| 编号 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| F1 | 导入视频 | 常见格式（mp4/mkv/mov/avi/webm 等，以 FFmpeg 支持为准），支持多选与拖入 | P0 |
| F2 | AI 超分 | 独立开关；模型可选（动漫 / 写实）；目标分辨率支持倍数（2x/3x/4x）或指定值（1080p/2K/4K/自定义） | P0 |
| F3 | AI 补帧 | 独立开关；目标帧率支持倍数（2x/4x）或指定值（如 60/120fps） | P0 |
| F4 | 导出视频 | 输出 mp4（H.264 + AAC），保留原音频；默认输出到源视频同目录 | P0 |
| F5 | 任务队列 | 列表展示全部任务；状态：等待中 / 处理中 / 已完成 / 失败 / 已取消；单任务顺序处理 | P0 |
| F6 | 任务操作 | 查看进度、取消、删除记录、失败重试 | P0 |
| F7 | 处理日志 | 每任务独立日志文件，界面内实时查看 | P0 |
| F8 | GPU 加速 | 超分 / 补帧走 Vulkan 调用 NVIDIA GPU；编码默认 NVENC | P0 |
| F9 | 设置 | 默认输出目录、编码器、GPU 编号、日志保留 | P1 |
| F10 | 任务持久化 | 关闭软件再打开，任务记录仍在；处理中任务恢复为等待中 | P1 |
| F11 | 显卡温度保护 | 处理中每 5 秒监控 GPU 温度并写入日志；超过上限（默认 88°C）自动安全停止任务并提示检查散热 | P1 |
| F12 | 内置使用教程 | 设置界面提供「使用教程」按钮，打开可滚动的中文 / 英文图文教程 | P2 |
| F13 | 语言切换 | 设置界面可选择简体中文 / English；保存后提示重启生效；界面、状态、日志阶段随语言切换 | P1 |

## 4. v1 非目标（明确不做）

- 处理前预览（截取片段试处理）——后续版本再考虑
- 更多语言（v1 仅简体中文与英语）
- macOS / Linux 版本
- 暂停 / 继续处理（v1 只有取消；重试从头开始）
- 文件夹批量导入、字幕处理、去噪 / 修复等附加 AI 功能
- 云端处理、账号系统

## 5. 已确认的需求决策

| 项目 | 决策 |
|---|---|
| 显卡 | RTX 30/40/50 系（速度较快） |
| 视频类型 | 动漫 + 真人都有 → 提供多模型下拉选择 |
| 处理偏好 | 平衡（速度与质量取中），默认参数按此设定 |
| 商用方式 | 作为商品卖给他人 → 需要安装包、授权合规、稳定性 |
| 界面语言 | 简体中文 + English（设置内切换，重启生效） |
| 界面风格 | 简洁直观，白色 + 淡蓝色 |
| 软件名称 | 暂定"NEX 视频增强"（正式商品名后续由用户确定） |
| 开发节奏 | 小步推进，每阶段停点向用户汇报确认 |
