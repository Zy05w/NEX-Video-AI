# 07 · 打包发布与授权合规

> 版本：v1.0（2026-11-21）· 实施阶段：S6-S7

## 1. 打包流程

1. 在干净虚拟环境安装锁定依赖：`pip install -r requirements.txt`。
2. PyInstaller **onedir** 模式：`pyinstaller build/nex.spec`。
   - 收集 PySide6 插件与图标资源；按需配置 hidden imports。
   - 引擎与模型不打进 `_internal`，作为 exe 同级 `engines/` 目录随安装包分发。
3. Inno Setup：`ISCC.exe build/installer.iss` 编译为中文/英文安装包。
   - 用户级安装（`PrivilegesRequired=lowest`），默认 `{autopf}\NEX`（即 `%LOCALAPPDATA%\Programs\NEX`），无需管理员权限。
   - 创建桌面 / 开始菜单快捷方式，自带卸载程序。
4. 在干净目录安装并完整处理一个视频（S6 验证）。

### 1.1 本轮构建结果（S6，2026-11-22）

- 程序：`dist/NEX/`（118MB）；入口 `NEX.exe`；应用图标 `nex/resources/nex.ico`；界面为 PySide6 原生控件 + QSS。
- 安装包：`dist/installer/NEX_Setup_0.1.0.exe`（**420MB**）。
- 安装内容：程序 + FFmpeg + Real-ESRGAN + RIFE（v4.6 / anime / HD / UHD）+ `licenses/`。
- 不包含：Practical-RIFE 4.25 与 PyTorch 环境（用户选择标准包；后续可做独立扩展包）。
- 安装后可用 `NEX.exe --self-test` 自检（报告写入 `%TEMP%\NEX_selftest.txt`）。
- 安装/卸载验证：静默安装、自检、冒烟、安装目录引擎处理、卸载均通过。

### 4.2 已知限制

- 第一版为逐帧 PNG 工作流：长视频 / 4K 会占用较大临时磁盘与较长时间；S7 已加入开始前磁盘预检与中间帧及时清理。
- NVENC 需要 NVIDIA 驱动 ≥610；不满足时使用 x264，编码速度较慢但兼容性最好。
- 目标分辨率以"目标高度"为准并保持源画面比例（例如 4:3 源选 1080p 输出 1440×1080），不会强制拉伸到 1920×1080。
- Practical-RIFE 4.25 为标准包之外的开发/高级选项，若后续随包分发需另做扩展包并补充 PyTorch 等许可证文本；其 Python/OpenCV 路径处理未针对 260+ 字符路径做专门适配（ncnn / FFmpeg 主流程已支持）。
