# 07 · 打包发布与授权合规

> 版本：v1.0（2026-11-21）· 实施阶段：S6-S7

## 1. 打包流程

1. 在干净虚拟环境安装锁定依赖：`pip install -r requirements.txt`。
2. PyInstaller **onedir** 模式：`pyinstaller build/nex.spec`。
   - 收集 PySide6 插件与 qfluentwidgets 资源；按需配置 hidden imports。
   - 引擎与模型不打进 `_internal`，作为 exe 同级 `engines/` 目录随安装包分发。
3. Inno Setup：`build/installer.iss` 编译为中文安装包。
   - 安装目录默认 `C:\Program Files\NEX`，创建桌面 / 开始菜单快捷方式，自带卸载程序。
4. 在干净目录安装并完整处理一个视频（S6 验证）。

## 2. 安装后布局

```
安装目录/
  nex.exe
  _internal/           # Python 运行时与界面库
  engines/             # ffmpeg.exe / ffprobe.exe / realesrgan-* / rife-* + models
  licenses/            # 许可证文本与源码获取说明
```

用户数据：`%APPDATA%/NEX/`（config.json、nex.db、logs/），卸载默认保留。

- Practical-RIFE：`Practical-RIFE/`（用户下载的 4.25 源码与 `train_log/flownet.pkl`）
- PyTorch：`https://mirrors.aliyun.com/pytorch-wheels/cu128/`（`torch-2.11.0+cu128-cp311-cp311-win_amd64.whl`）

已归档的许可证文件（`licenses/`）：
- `Real-ESRGAN-LICENSE.txt`（BSD-3-Clause）
- `RIFE-LICENSE.txt`（MIT）
- `FFmpeg-GPLv3.txt`（GPL v3 全文）
- `FFmpeg-SOURCE-OFFER.txt`（构建信息与源码地址）
- `Practical-RIFE-LICENSE.txt`（MIT，含 4.25 权重许可说明）

**FFmpeg GPL 合规做法**：以独立可执行文件分发、由主程序以子进程调用；安装包内 `licenses/FFmpeg-GPL.txt` 附 GPL 全文，`licenses/SOURCE-OFFER.txt` 说明获取对应源码的官方地址；软件"关于"页同样展示。默认编码器使用 `h264_nvenc`（驱动接口），不以 x264 为主要分发路径。
