## S0 项目基建与文档体系

- **停点**：向用户展示项目结构，确认后进入 S1。

## S1 引擎下载与实测核验

- **产出**：`engines/realesrgan`、`engines/rife` 及模型；FFmpeg 就绪；许可证归入 `licenses/`；实测记录回填 `docs/02` 第 8 节与 devlog。
- **验证**：3 秒测试片段跑通抽帧、超分、补帧、合成；中文路径专项测试；GPU 温度记录。
- **实测结果**：超分 72 帧 4.6 秒、补帧 72→144 帧 5.1 秒、x264 合成 0.6 秒；中文+空格路径通过；GPU 负载温度 50°C。发现新版 FFmpeg 移除 `-vsync`（改用 `-fps_mode`）、引擎须以其目录为工作目录、NVENC 需驱动 ≥610（当前 582.05）。
- **停点**：汇报实测参数、模型清单与体积、耗时；确认 NVENC 处理方案后再进入 S2。

## S2 界面骨架（假数据）

- **验证**：`python -m nex --smoke-test` 退出码 0；真实窗口截图确认中文、布局、配色符合 docs/03。
- **实测结果**：离屏与真实窗口均正常启动；任务表格、进度条、状态颜色、日志面板、对话框均可用；Git 已安装并提交版本。
- **停点**：用户实际打开界面提修改意见。

## S3 处理管线（命令行先行）

- **产出**：`engines.py`（引擎封装）、`pipeline.py`（编排/进度/取消/清理）、`logger.py`（任务日志）、`cli.py`（headless 入口）。
- **验证**：ffprobe 校验输出分辨率 / 帧率 / 音频 / 时长；命令行下进度与取消可用；单任务处理样本并记录耗时。
- **实测结果**：只超分 4.6s / 只补帧 3.0s / 组合 8.2s（3 秒 640×360 样本）；1080p+60fps 任意目标 10.8s（1 秒样本）；中文路径、无音轨、取消（130）、错误路径均通过。详见 docs/02 第 8 节。
- **温度保护（补充）**：实测满载 96% 占用时最高 57°C、功耗 65.8W（上限 66.4W）；新增 GPU 温度监控，默认 88°C 上限，超限安全停止，已用模拟阈值验证。
- **停点**：汇报样本结果与耗时，用户确认质量方案。

## S4 队列、持久化与日志

- **产出**：`task.py`（任务模型）、`db.py`（SQLite + WAL）、`worker.py`（QThread 顺序消费、进度 / 日志信号、取消）、界面表格改为真实任务模型、日志面板读取任务日志文件。
- **验证**：处理中强杀进程再启动，任务仍在可继续；取消后临时目录清理干净；数据库 / 工作线程测试通过。
- **实测结果**：真实任务经工作线程完成（进度 100、输出与日志存在）；取消任务保留进度（12%）并记录日志；强杀进程后数据库中"处理中 45%"重启恢复为"等待中 0%"；遗留临时目录可清理。详见 docs/06 第 1.2 节。
- **停点**：汇报队列与日志行为，等待用户试用确认。

## S5 界面与引擎整合

- **产出**：界面"添加任务 → 队列 → 处理 → 完成"全链路跑通；修复设置数字框（日志天数 / 温度上限）显示与输入问题；日志面板与引擎原始输出分离；实现日志保留天数清理；设置界面新增「使用教程」按钮与内置图文教程；新增语言切换（简体中文 / English，界面、状态与日志均翻译）；接入可选 Practical-RIFE 4.25（PyTorch）补帧引擎。
- **验证**：真实界面中完成单任务、取消、多任务顺序队列、失败重试；按 docs/06 冒烟清单核对。
- **实测结果**：单任务 100% 完成且输出/日志存在；取消保留进度 13%；两个任务顺序完成；取消任务重试后完成；日志面板仅显示结构化日志（约 11 行）；设置数字框可显示、键盘输入与箭头调节；Practical-RIFE 4.25 在 360p/720p 推理与全管线通过，环境缺失时提示清晰。详见 docs/06 第 1.3 节。

## S6 打包与安装包

- **产出**：`build/nex.spec`（PyInstaller onedir）、`build/nex_launcher.py`、`build/installer.iss`（Inno Setup 中文/英文）、应用图标 `nex/resources/nex.ico`、`licenses/` 齐备。
- **验证**：干净目录安装 → 运行自检 → 界面冒烟 → 用安装目录引擎处理视频 → 卸载。
- **实测结果**：PyInstaller 产物 **118MB**；安装包 **420MB**；静默安装到 `.test/install`；安装后 `NEX.exe --self-test` 返回 OK；界面冒烟通过；安装目录引擎处理 1 秒视频输出 1280×720/48fps；关闭程序后卸载干净；安装目录内无 qfluentwidgets。
- **说明**：当前为用户级安装（无需管理员），默认安装到 `%LOCALAPPDATA%\Programs\NEX`；标准包不含 Practical-RIFE 4.25（按用户选择），4.25 作为后续可选扩展。
- **许可问题已解决**：qfluentwidgets 为 GPLv3，已替换为 PySide6 原生控件 + 自定义 QSS；qfluentwidgets 已从依赖和安装包中移除，可闭源商用。
- **停点**：汇报安装包位置与体积，等待用户安装试用确认。
