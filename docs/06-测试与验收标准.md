## 3. 端到端验收标准（v1 发布门槛）

1. 双击安装 → 打开软件 → 导入动漫与真人样本各一 → 分别执行"只超分 / 只补帧 / 超分+补帧"。
2. 输出分辨率、帧率、音频与设置完全一致（ffprobe 核验）。
3. 处理中取消 → 状态正确、临时文件清理干净；删除记录无残留；重启后任务列表完整。
4. 日志面板实时滚动，失败任务日志能定位原因。
5. `licenses/` 包含全部组件许可证文本，"关于"页可查。
6. docs 7 份文件与 devlog 持续更新且与实现一致；CLAUDE.md 索引路径有效。

## 4. 缺陷等级

| 等级 | 定义 | 处理 |
|---|---|---|
| P0 | 崩溃、数据丢失、输出错误 | 立即修复，阻塞发布 |
| P1 | 主要功能异常、明显体验问题 | 发布前修复 |
| P2 | 次要问题、文案 / 样式 | 可延后，记入 devlog 待办 |
